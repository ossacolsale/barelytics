Daily browser reach reports

This metric counts first daily reports received from browsers participating in optional measurement. It is not an exact count of people or all unique visitors.

Concurrent tabs coordinate locally. Storage rejection and network failures miss observations; storage clearing, eviction, separate devices and forged requests can inflate counts. Shared browsers can combine people. JavaScript-disabled visits are absent. These reports and server page views may cover different populations; no per-page uniques or verified conversion ratio is provided.

Optional dimensions

Privacy configuration

No analytics cookies or browser identifiers are used. Strict does not access analytics browser storage. Optional site-wide Daily Reach uses one IndexedDB day marker; Daily Page Reach adds bounded, expiring local page hashes in Extended measurement; it is controlled centrally here for the normal browser tracker and requires the operator’s consent or exemption assessment. Use the host/CMP permission callback when required. Reporting days run from 00:00 to 00:00 UTC. Disabling optional measurement stops future collection and retains historical aggregates until retention cleanup or deletion.
