# Who Barelytics is for

Barelytics is for personal sites, portfolios, small publications, and modest applications whose owners need aggregate page totals and can maintain a local SQLite database. It suits PHP shared hosting through the FTP/SFTP package and persistent Node, Python, .NET, Java, and Ruby deployments through native packages.

Barelytics is a poor fit when an organization needs cross-device identity, detailed conversion attribution, experimentation, session replay, large-scale event analytics, managed uptime, or dashboards without operating its own storage. It does not measure unique people. Consider the reporting needs and operational skills before choosing it.
