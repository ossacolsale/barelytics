# Barelytics compared with hosted analytics

| | Barelytics | Hosted analytics service |
| --- | --- | --- |
| Data location | Your application's local SQLite storage | Provider infrastructure |
| Default metric | Aggregate page views | Varies by service and configuration |
| Visitor identity | None in Strict Mode | May include IDs, sessions, or profiles |
| Setup | Install and operate the runtime yourself | Create an account and connect the service |
| Reporting | Compact page/day aggregates and optional dimensions | Often broader funnels, attribution, and product features |
| Operations | You manage backups, upgrades, access, and retention | Provider manages infrastructure under its service terms |

Barelytics fits owners who want local aggregate counts and can operate their own data store. It is not a substitute for detailed attribution, user journeys, experimentation, or managed reporting. Capabilities of other products vary; review their current documentation and settings before comparing a deployment.
